# Software Engineering Lab

A practical laboratory for learning software engineering fundamentals, tools, and professional development workflows.

## Purpose

This repository is used to practice and document software engineering concepts through hands-on exercises and small projects.

## Topics

- Git and GitHub
- TypeScript
- React / Next.js
- Python
- FastAPI
- HTTP and REST APIs
- PostgreSQL and SQL
- Testing
- Docker
- AI and LLM APIs
- RAG and embeddings
- Data Structures and Algorithms

## Goals

- Build strong software engineering fundamentals
- Practice professional development workflows
- Develop projects using modern technologies
- Improve problem-solving and algorithmic thinking
- Document the learning process
